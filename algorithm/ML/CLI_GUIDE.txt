═══════════════════════════════════════════════════════════════════════════════
[1] ATTENTION MODEL (Transformer-based Reinforcement Learning)
═══════════════════════════════════════════════════════════════════════════════

[Vị trí] NeuralCombinatorialOptimization/Attention-Model/

Mô tả: Sử dụng Attention Mechanism (Transformer) kết hợp với RL để học cách giải VRPTW

BƯỚC 1: Training Model
-----------------------------------------------------------
cd NeuralCombinatorialOptimization/Attention-Model
python train.py

Tham số training:
  --n-epochs N         Số epochs (mặc định: 100)
  --batch-size N       Batch size (mặc định: 64)
  --lr RATE           Learning rate (mặc định: 0.001)
  --embedding-dim N    Embedding dimension (mặc định: 128)

BƯỚC 2: Test với Trained Model
-----------------------------------------------------------
# Test một dataset
python attention_vrptw_solver.py

# Test tất cả datasets
python test_all_datasets.py

Kết quả: result/images/, result/text/, result/test_summary.csv
Model: models/attention_model_best.pth

═══════════════════════════════════════════════════════════════════════════════
[2] DQN-RL (Deep Q-Network Reinforcement Learning)
═══════════════════════════════════════════════════════════════════════════════

[Vị trí] NeuralCombinatorialOptimization/DQN-RL/

Mô tả: Sử dụng Deep Q-Network để học policy giải VRPTW thông qua trial-and-error

BƯỚC 1: Training Model
-----------------------------------------------------------
cd NeuralCombinatorialOptimization/DQN-RL
python train.py

Tham số training:
  --n-episodes N       Số episodes (mặc định: 1000)
  --batch-size N       Batch size (mặc định: 64)
  --lr RATE           Learning rate (mặc định: 0.001)
  --gamma RATE        Discount factor (mặc định: 0.99)

BƯỚC 2: Test với Trained Model
-----------------------------------------------------------
# Test một dataset
python dqn_vrptw_solver.py

# Test tất cả datasets
python test_all_datasets.py

Kết quả: result/training_curves.png
Model: models/dqn_model_best.pth
