[3] Parameters:
-------------------------------------------------------------------------------
--capacity INT           : Sức chứa xe (mặc định: 200)
--max-vehicles INT       : Số xe tối đa (mặc định: 25)

Sweep Algorithm Parameters:
--start-angle FLOAT      : Góc khởi đầu quét theo độ (0-360, mặc định: 0)
                           Thuật toán quét từ góc này theo chiều kim đồng hồ

--category C1|C2|R1|R2|RC1|RC2  : Chỉ test category này (test_all_datasets.py)
--limit INT              : Giới hạn số dataset test (test_all_datasets.py)
--no-save                : Không lưu kết quả (sweep_vrptw_solver.py)
