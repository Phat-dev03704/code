Simulated Annealing Parameters:
--initial-temp FLOAT     : Nhiệt độ ban đầu (mặc định: tự động dựa vào dataset)
--final-temp FLOAT       : Nhiệt độ cuối (mặc định: 0.1)
--cooling-rate FLOAT     : Tỷ lệ làm lạnh (0.9-0.99, mặc định: 0.95)
                           Càng cao → làm lạnh càng chậm → tìm kiếm kỹ hơn
--max-iter INT           : Số iterations tối đa (mặc định: tự động)
--time-limit INT         : Giới hạn thời gian (giây)

--category C1|C2|R1|R2|RC1|RC2  : Chỉ test category này (test_all_datasets.py)
--limit INT              : Giới hạn số dataset test (test_all_datasets.py)
--no-save                : Không lưu kết quả (sa_vrptw_solver.py)
